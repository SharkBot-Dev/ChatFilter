# ChatFilter
🧹スパムや招待リンクをきれいに排除します。

# セットアップ方法
1. 最新のリリースからchatfilter.exeをダウンロードします。
2. DiscordDeveloperでBotを作成し、メッセージ特権インテントを有効にし、Tokenを取得します。
3. 「.env」というファイルを作成し、以下の記述します。
```
DISCORD_TOKEN=Discord Developerで作成したBotのToken
OWNER_ID=Botの管理者のDiscordユーザーID
```
4. あとはchatfilter.exeを起動し、エラーが出なければ成功です。
5. 作成したBotに管理者権限を与えてサーバーに招待してください。
6. %pingと入力し、Pong!と返ってくれば成功です。
7. /setupと入力し、実行します。
8. モデレーターログチャンネルが作成され、招待リンクが自動で排除されるようになります。
9. サブ垢で試して、メッセージが削除され、3分間タイムアウトされたら成功です。

# コマンド一覧
スラッシュコマンド一覧です👇️
- /automod AutoModルールを有効化します。
- /modlog モデレーターログチャンネルを指定します。
- /whitelist チャンネルをホワイトリストに追加します。
- /setting 現在の設定を確認をします。
- /setup 最初のセットアップします。
- /help ヘルプを表示します。
管理者専用コマンド一覧です👇️
- %ping Botが動いているかを確認します。
- %shutdown Botをシャットダウンします。
